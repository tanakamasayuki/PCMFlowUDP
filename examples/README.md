# PCMFlowUDP examples

## Workflow and individual READMEs

Start with the [example workflow](../docs/GUIDE_EXAMPLES.md), then choose the relevant sketch.

A useful starting point is [EspToEspRaw](EspToEspRaw/README.md). Check its required hardware and choose another entry below if it does not match your setup.

| Example | Learn |
|---|---|
| [EspToEspRaw](EspToEspRaw/README.md) | Exchange raw PCM byte chunks over UDP |
| [RtpVoipG711](RtpVoipG711/README.md) | Send and decode G.711 packets over RTP |
| [VbanMicToPc](VbanMicToPc/README.md) | Send PCM packets using the VBAN format |
